# Kanji Dōjō

Application web de révision du japonais (kanji, vocabulaire, lecture, dictionnaire).

## Sources de données

- **KANJIDIC** et **JMdict / EDICT** — © Electronic Dictionary Research and Development Group (EDRDG), licence [CC BY-SA 4.0](https://www.edrdg.org/edrdg/licence.html). Version « simplified » de [scriptin/jmdict-simplified](https://github.com/scriptin/jmdict-simplified).
- Données kanji : [davidluzgouveia/kanji-data](https://github.com/davidluzgouveia/kanji-data).
- Composants des kanji : [KanjiVG](https://github.com/KanjiVG/kanjivg) (CC BY-SA 3.0).
- Phrases d'exemple : [Tatoeba](https://tatoeba.org) (CC BY 2.0 FR), paires japonais–français.
- Traductions françaises complémentaires rédigées pour l'application.

- Niveaux JLPT des mots : listes communautaires (Tanos) via [elzup/jlpt-word-list](https://github.com/elzup/jlpt-word-list), licence MIT.
- Accent de hauteur : Kanjium (mifunetoshiro/kanjium), base d'Uros O., licence CC BY-SA 4.0.
